# Day 2 — Variables, Types & I/O

## What I Learned

- **Variables** store values that can be reused in a program.
- Python automatically determines a variable's basic data type.
- Common types: `str`, `int`, `float`, `bool`.
- `print()` displays information in the terminal.
- `input()` accepts user input and returns it as a **string by default**.
- **f-strings** allow variables and expressions to be embedded inside text.
- Expressions inside an f-string can be evaluated when placed inside `{}`.
- **Parentheses** control the order of mathematical operations.
- `:.2f` formats a number to **two decimal places**, useful for currency.
- Avoid hardcoding values when they can be calculated from existing variables.

## Important Lesson

There is a difference between **text that looks like a calculation** and an actual calculation.

An f-string can insert values into text, but Python won't automatically evaluate a resulting string as a mathematical expression.
